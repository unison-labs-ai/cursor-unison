---
name: unison-setup
description: Connect Unison Brain to Cursor for persistent AI memory
---

Run the following command in the terminal to authenticate:

```bash
bunx cursor-unison@latest login --email you@example.com
```

This provisions a Unison brain account and emails you a verification code. Enter the code when prompted.

If you already have an account and need to recover your API key:

```bash
bunx cursor-unison@latest login --email you@example.com --recover
```
